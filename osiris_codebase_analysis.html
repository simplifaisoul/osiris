01. What the Project Does Core Capabilities

OSIRIS (Open Source Intelligence & Reconnaissance Integrated System) is an enterprise-grade, real-time situational awareness platform. It consolidates disparate geospatial, cyber, space, maritime, flight, financial, and geopolitical intelligence feeds into a single GPU-accelerated 3D globe and 2D tactical map view.

✈️ Aviation & Space Tracking

  • Live ADS-B Aircraft Telemetry: Real-time positioning, altitude, squawk codes, and flight trajectories for commercial, private, jet, and military aircraft via OpenSky Network.
  • Satellite Orbit Propagation: SGP4 orbital calculations using TLE sets for over 10,000 active satellites (ISS, Starlink, military, Earth observation, GPS).
  • Space Weather Monitoring: NOAA SWPC Kp-index, solar flare warnings, geomagnetic storm telemetry, and live SpaceCam ISS streaming.

🌊 Maritime & Physical Infrastructure

  • Global Naval Operations: AIS live ship tracking across 39 strategic global ports and 10 vital maritime chokepoints (Suez, Panama, Bab-el-Mandeb, etc.).
  • Infrastructure Overlay: Submarine telecom cables, nuclear power facilities, oil pipelines, and supply chain logistics nodes.
  • CCTV Network: 17,000+ global webcams indexed across Texas (TxDOT), London (TfL), California (Caltrans), Netherlands (Rijkswaterstaat), and bekijkhet.nu catalogue.

⚡ Cyber Security & Tactical RECON

  • Target Scanner: Active TCP port connect scanning, service fingerprinting, WHOIS lookup, SSL/TLS cert chain inspection, and DNS record expansion.
  • Threat Intelligence: NVD CVE vulnerability mapping, Feodo Tracker botnet C2 servers, ThreatFox/URLhaus malware feeds, and Cloudflare Radar outage telemetry.
  • Sherlock OSINT: Multi-threaded username footprinting across 480+ social platforms with soft-404 verification algorithms.

🌐 Geopolitics, Sanctions & Financial Crypto

  • OFAC SDN Graph Match: Cross-checks WHOIS registrants, IP ASN owners, flight callsigns, and crypto addresses against 70,000+ US OFAC SDN sanctioned entities.
  • Crypto Wallet Trace: Keyless Bitcoin (Blockstream Esplora) and Ethereum (Blockscout) address balance and transaction history tracing.
  • Geocoded Telegram OSINT: Scrapes unauthenticated public channels (t.me/s/) and geoparses posts via multilingual place dictionaries onto map coordinates.

03. Tech Stack Architecture Modern Stack

🎨 Frontend & Visualization

  • Next.js 16 (App Router): React 19 framework utilizing Server Components, Turbopack, and dynamic chunk lazy loading.
  • MapLibre GL JS: WebGL GPU-accelerated mapping engine for smooth 60fps rendering of 50,000+ vector entities on 3D globes and 2D flat projections.
  • satellite.js: SGP4 orbital mechanics library for real-time satellite trajectory calculation.
  • Turf.js: Spatial analysis, polygon tripwires, and geospatial point-in-polygon calculations.
  • Framer Motion & Lucide: Micro-animations, responsive slide-over HUDs, and vector iconography.

🧠 Backend Services & Intelligence

  • osiris-intel (Node.js Microservice): Express graph ontology server (`intel/server.js`) parsing OpenSanctions CSV into memory and proxying Wikidata SPARQL queries.
  • Next.js Edge API Routes: 43+ API endpoints handling SSRF protection, caching, rate limiting, and feed transformation.
  • RECON Engine: Low-level TCP socket connect scanner, TLS certificate inspector, WHOIS protocol client, and DNS resolver.
  • Sherlock JS Engine: Custom TypeScript port of Sherlock Python scanner for username enumeration across 480+ platforms.

🐳 Deployment & Operations

  • Docker & Compose: Lightweight multi-stage node:22-alpine standalone container build (~220MB).
  • CasaOS Ecosystem: Embedded CasaOS app manifest (x-casaos:) for one-click homelab integration.
  • Vercel Edge Network: Edge network deployment readiness with aggressive HTTP stale-while-revalidate headers.
  • Vitest Testing Framework: Unit testing suite covering API endpoints, SSRF guards, geocoders, and polygon math.

04. Code Flow & Architecture Data Pipeline

The OSIRIS architecture is designed around high concurrency, client-side WebGL rendering, and tight security isolation. Below is the end-to-end data flow from external OSINT sources to the WebGL GPU canvas:

Detailed Code Flow Summary

  1. Client Component Mount & State Initialization: src/app/page.tsx loads as a client component. On startup, it triggers lightweight, keyless core feeds (USGS Earthquakes, global news, severe weather).
  2. Progressive Layer Lazy Loading: As the user toggles map layers in LayerPanel.tsx, state updates trigger specific endpoint fetches. Duplicate fetches are blocked via layerFetchedRef, cutting API traffic by up to 75%.
  3. SSRF Guard & API Proxying: All outbound client requests pass through Next.js API routes where ssrf-guard.ts verifies target hostnames against strict domain allowlists and prevents internal IP network scanning.
  4. Entity Resolution via `osiris-intel`: When resolving an entity (e.g. aircraft callsign, IP address, vessel, company), the API routes query http://localhost:4000/resolve. The standalone microservice executes safe SPARQL queries against Wikidata and matches results against an in-memory graph of 70,000+ OFAC SDN sanctioned entities.
  5. WebGL GPU Render Pipeline: Received JSON payloads are loaded into OsirisMap.tsx. MapLibre GL creates GeoJSON sources rendered dynamically via WebGL shaders, maintaining 60fps performance even with thousands of active entities.

05. Future Feature Expansion Roadmap Recommendations

Based on our code analysis, OSIRIS possesses a robust, modular foundation. Here are 7 innovative, high-impact features that can be added to elevate the platform to an elite OSINT standard:

AI / LLM Integration
1. AI-Powered Automated Threat Synthesis & Incident Briefings
Integrate LLM orchestration (e.g. Gemini 1.5 Pro / Claude 3.5 Sonnet API) to correlate multi-domain events in real time. For example, automatically detect when a military aircraft cluster coincides with a thermal fire spot (FIRMS) and a Telegram war report, generating an automated tactical intelligence summary banner on the HUD.
Tech: Next.js Server Sent Events + Vercel AI SDK + Structured JSON Schema output
Machine Learning
2. Predictive Anomaly Detection for Flight & Vessel Telemetry
Implement real-time trajectory anomaly detection to identify AIS/ADS-B spoofing, sudden unauthorized flight altitude drops, dark fleet vessel ship-to-ship rendezvous in sanctioned waters, or military asset concentrations along international borders.
Tech: Python Microservice / WebAssembly (Wasm) + DBSCAN / Isolation Forests + Turf.js
Collaboration
3. Multi-User Tactical War Rooms & Live Workspace Sync
Enable multi-investigator collaboration ("Tactical War Rooms"). Analysts can join shared room sessions via WebSockets, allowing real-time cursor sharing, joint AOI drawing, dropped target pins, tactical chat, and voice channels.
Tech: Socket.io / PartyKit / Yjs CRDTs for multiplayer state synchronization
Hardware Integration
4. Local Dump1090 RTL-SDR & Custom Webhook Data Connector
Allow field operators to connect local hardware receivers (e.g. RTL-SDR dongles running dump1090 for direct local ADS-B decoding, or local AIS antennas) directly into OSIRIS over local WebSocket / REST endpoints.
Tech: Local WebSockets API + Dump1090 JSON protocol parser + UI Data Pipeline Configurator
Time Series
5. Historical Replay & Time Machine DVR Mode
Store telemetry states in a time-series database to enable a "Time Machine" slider on the dashboard. Analysts can scrub backwards in time to replay troop movements, flight paths, and news feeds leading up to major geopolitical events.
Tech: ClickHouse / TimescaleDB + MapLibre animation timeline controls
Satellite Remote Sensing
6. Automated SAR & Optical Satellite Change Detection over AOIs
When an analyst draws a polygon AOI, automatically query Sentinel-1 (Synthetic Aperture Radar) and Sentinel-2 optical imagery to perform differential change detection (building damage assessment, new airstrip construction, oil slick detection).
Tech: Copernicus Data Space Ecosystem API + Sentinel Hub API + OpenCV / WebGL Shader Diffing
Off-Grid PWA
7. Off-Grid PWA with Meshtastic Mesh Radio Integration
Transform OSIRIS into a Progressive Web App (PWA) with offline vector tile caching and Bluetooth LE connection to Meshtastic hardware radios, allowing off-grid tactical teams to broadcast map markers and GPS locations without cellular or internet connectivity.
Tech: Service Workers + Web Bluetooth API + Meshtastic Protobuf Protocol
